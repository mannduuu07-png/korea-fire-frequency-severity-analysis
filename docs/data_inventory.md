# Data Inventory

| Dataset | Purpose | Key Fields | Geo Level | Time Level | Status |
|---|---|---|---|---|---|
| National Fire Agency Annual Fire Statistics (2015–2024) | Phase 1 main dataset | date, province, district, casualties, property damage, place type | 시군구 / Incident | Incident | Acquired and analyzed |
| Building Register Data | Structural risk factors | approval year, use, structure, location | Building / 시군구 | Current or annual | Planned for Phase 2 |
| KOSIS Population Data | Demographic vulnerability | population, elderly population, single-person households | 시군구 | Annual | Planned for Phase 2 |
| Fire Station Location Data | Fire-service accessibility | station type, address, coordinates | Facility / 시군구 | Reference year | Planned for Phase 2 |
| Administrative Boundary Data | Mapping and spatial joins | region code, geometry | 시군구 | Reference year | Planned for Phase 2 |

Raw fire-statistics files are not included because of their size.  
The Phase 1 analysis uses ten annual CSV files published by the National Fire Agency through data.go.kr.
